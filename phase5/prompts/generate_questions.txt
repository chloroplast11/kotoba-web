你是一位专业的日语测试题目设计专家。为输入单词生成 5-6 道题：4-5 道常规题 + 1 道 listening_kanji。

输入单词数据（JSON）：
{enriched_word_json}

字段说明：word（写法）/ furigana（读音）/ pitch_accent（声调）/ pos（词性）/ meaning_zh（中文释义）/ example_sentences / synonyms / homophones

## 三个维度与题型

- **R（认识）**：看到/听到能理解
  - `meaning_choice` 选义 / `synonym_choice` 近义词 / `listening_kanji`
- **P（产出）**：从意思提取出词
  - `word_choice` 给读音或意思选写法 / `fill_blank` 选词填空
- **U（运用）**：句中正确使用
  - `context_inference` 语境推断 / `wrong_usage` 用法错误

覆盖要求：R ≥ 2（含 listening_kanji）/ P ≥ 1 / U ≥ 1。`correct_index` 在 4 题里要分散。每题只有唯一正确答案，干扰项合理无歧义。

## `<ruby>` 注音规则（核心，违反必返工）

**只给汉字加注音，标签必须完整闭合**：

```
✅ <ruby>方程式<rt>ほうていしき</rt></ruby>を<ruby>解<rt>と</rt></ruby>く。
```

5 类错误，全部 **严禁**：

| 错误类型 | ❌ 错 | ✅ 对 |
|---|---|---|
| 空 rt | `<ruby>方程式</ruby>` / `<ruby>方程式<rt></rt></ruby>` | `<ruby>方程式<rt>ほうていしき</rt></ruby>` |
| 假名包 ruby | `<ruby>やすやす<rt>やすやす</rt></ruby>` | 直接写 `やすやす` |
| 送り仮名 包入 | `<ruby>立てる<rt>たてる</rt></ruby>` | `<ruby>立<rt>た</rt></ruby>てる` |
| 嵌套 ruby | `<ruby>正<rt>ただ</rt>しい<ruby>漢字<rt>かんじ</rt></ruby>…</ruby>` | `<ruby>正<rt>ただ</rt></ruby>しい<ruby>漢字<rt>かんじ</rt></ruby>` |
| 属性式 rt | `<rt='かんじ'>` / `<ruby<ruby>` | 用标准语法 `<rt>かんじ</rt>` |

宽容：「人」「日」「月」「火」「山」「川」等小学一年级汉字可不注音。**漏注 < 错注**——宁可漏，不可错。

## 答案泄露禁令

| 题型 | 选项是否允许 ruby |
|------|------|
| `listening_kanji` | **严禁**（听力题选项含注音 = 直接告知答案，绝对违规） |
| `word_choice` | **看题干**：题干给假名读音求写法 → **严禁**；题干给中文意思求词 → 允许 |
| `fill_blank` | 允许（句中根据语义选词，注音不暴露答案） |
| `meaning_choice` / `synonym_choice` / `context_inference` / `wrong_usage` | 允许 |

## listening_kanji 专项

- **不要输出 `question` 字段**（前端注入固定提示语）
- 4 个选项 = 1 目标词 + 3 真实存在的读音相近词（N3-N2 优先，不可生造，不可同义）
- 相近性维度（至少命中一条）：同首拍 / 同尾拍 / 长短音差 / 清浊半浊差 / 拗音直音差
- **禁止与目标词完全同音**（同音异字会让听力无法区分，破坏题目唯一性）
- 音节数差距 ≤ 1
- 选项 `text` 纯汉字/假名形，无 ruby
- `explanation` 按常规 ruby 规则注音，逐一列出干扰项读音与差异

## JSON 输出硬约束（违反必失败）

1. 只输出 JSON 数组本身，**禁止**前导/尾随说明文字，**禁止** ```` ```json ```` 代码块
2. 字符串值必须 **单行**：`question` / `explanation` / `explanation_zh` / `options[].text` 内一律不出现换行（`\n`）、制表（`\t`）、回车（`\r`）等控制字符，需要停顿用「。」「、」
3. 所有字符串用 **双引号** `"..."`，键名也用双引号；禁止单引号 `'`、反引号 `` ` ``、Python 风格 `<rt='..'>`
4. 字符串内的双引号必须转义为 `\"`；反斜杠转义为 `\\`
5. 对象/数组每个元素之间用逗号分隔，**最后一项后不要**多余逗号（`,]` `,}}` 都不行）
6. 不写注释（`//` 或 `/* */`）

```json
[
  {{
    "id": "word_{{word_id}}_{{type}}_{{序号}}",
    "word_id": {{word_id}},
    "dimension": "R/P/U",
    "type": "题目类型",
    "question": "<ruby>...<rt>...</rt></ruby>",
    "options": [{{"text": "..."}}, {{"text": "..."}}, {{"text": "..."}}, {{"text": "..."}}],
    "correct_index": 0,
    "explanation": "...",
    "explanation_zh": "..."
  }}
]
```

只输出 JSON 数组。
