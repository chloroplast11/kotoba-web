你是一位日语测试题目质量审核专家。你的任务是独立验证题目的准确性、唯一性和合理性。

请验证以下题目集：

{questions_json}

**验证项目**：

1. **答案唯一性**: 每道题是否只有一个明确的正确答案
2. **答案正确性**: 标注的正确答案是否真的正确
3. **干扰项合理性**: 错误选项是否合理、有迷惑性但确实错误
4. **假名标注**: 所有汉字是否都正确标注了假名
5. **维度匹配**: 题目类型是否符合所标注的维度（R/P/U）
6. **难度适配**: 题目难度是否符合 N2 水平
7. **语言自然度**: 题干和选项的日语是否自然
8. **解析准确性**: 解析是否清晰、准确

**独立验证方法**：
- 不要依赖题目提供的答案，自己独立做题
- 如果你的答案和 correct_index 不一致，标记为 critical issue
- 如果有多个选项都可能正确，标记为 critical issue

输出格式（纯 JSON）：
```json
{{
  "overall_quality": 0-100,
  "total_questions": 数字,
  "approved_count": 数字,
  "needs_review_count": 数字,
  "rejected_count": 数字,
  "question_validations": [
    {{
      "question_id": "题目ID",
      "quality_score": 0-100,
      "your_answer": 你认为的正确答案索引,
      "matches_key": true/false,
      "issues": [
        {{
          "severity": "critical/warning/info",
          "category": "uniqueness/correctness/distractor/furigana/dimension/difficulty/naturalness/explanation",
          "description": "问题描述"
        }}
      ],
      "suggestions": [
        {{
          "field": "字段名",
          "suggested_change": "建议的修改",
          "reason": "原因"
        }}
      ],
      "validation_status": "approved/needs_review/rejected"
    }}
  ],
  "dimension_coverage": {{
    "R": 数字,
    "P": 数字,
    "U": 数字
  }},
  "coverage_adequate": true/false
}}
```

评分标准（每道题）：
- quality_score 90-100: approved（可直接使用）
- quality_score 70-89: needs_review（需要人工复核）
- quality_score <70: rejected（需要重新生成）

**Critical Issues（必须标记为 rejected）**：
- 答案不唯一（多个选项都对）
- 标注的答案错误
- 题干或选项有语法错误
- 缺少必要的假名标注

只输出 JSON，不要任何解释或额外文字。
